# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Apple Native
- **Notes:** Generous spacing on an 8pt grid, one unified corner radius (16px cards, 12px controls, full pill only for the scan button), neutral palette, fluid but short transitions. Dark-only UI built on the three brand colors below. Arabic-first (RTL) with English; font IBM Plex Sans Arabic / IBM Plex Sans.

### Brand colors (the only three UI colors)

| Token | Hex | Role |
|---|---|---|
| `--ink-black` | `#11151C` | Page background, primary button text |
| `--deep-space-blue` | `#212D40` | Cards, sheets, bottom navigation |
| `--charcoal-blue` | `#364156` | Borders, dividers, inputs, chips, active nav background, chart track |

Supporting (not brand) colors:

- Text `#F3F5F9` (16.8:1 on ink black, 12.7:1 on cards). Primary buttons use this as the fill with ink-black text.
- Muted text `#B9C3D3` (10.3:1 on ink black, 7.8:1 on cards). Never place muted text on charcoal blue (5.8:1 fails AAA).
- Verdict status colors, used only for verdicts, traffic-light pills and the chart, always with an icon and a word:
  good `#86EFAC`, moderate `#FCD34D`, avoid `#FCA5A5` (all ≥ 7.3:1 on cards).

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs
- Emoji anywhere in the UI (navigation, buttons, verdicts, reasons, tips, empty states). Use Lucide icons instead.

## Accessibility target

- **Level:** WCAG 2.1 AAA
- **Contrast:** Normal text ≥ 7:1, large text (≥ 24px, or ≥ 19px bold) ≥ 4.5:1, borders and chart marks ≥ 3:1 against their surface. Check every text color against the surface it sits on, not only the page background.
- **Touch / focus:** Touch targets ≥ 48×48px. Visible 3px focus outline in `#F3F5F9` with 2px offset on every interactive element. Status is never shown by color alone. Respect `prefers-reduced-motion`.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** State facts and numbers plainly ("Sugar: 18 g per 100 g"). No exclamation marks, no cheerleading, no filler. Buttons start with a verb ("Scan product", "Choose this"). Errors say what happened and the next step, never blame the user.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react` (app); `lucide` UMD for static mockups
- **Notes:** One stroke width (2px), 20px in lists, 24px in navigation. Do not mix with other icon sets.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
